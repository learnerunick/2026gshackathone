# 일시정지·중지·재개 검토

2026-09-21. 실제 제작 데이터를 변경하지 않는 격리 DB·가짜 공급자·테스트 프로세스로 검증했다.

## 확인하고 수정한 오류

1. 영상 제출 허용 여부 확인과 제출 상태 저장 사이에 중지·일시정지가 들어와도 유료 요청을 보낼 수 있었다. 준비·전송 상태 전환을 실행 상태 확인과 같은 SQLite 쓰기 트랜잭션으로 묶었다. 중지 커밋 이후에는 새 전송 예약을 잡지 않는다. 이미 전송 예약을 잡은 작업은 진행 중인 외부 요청으로 보존한다.
2. 중지한 실행의 제출 전 영상이 작업자 조회 때까지 큐에 남았고, 취소 후에도 미디어 단계가 실행 중으로 남을 수 있었다. 종료 시 제출 전 큐·단계·소유권을 함께 취소하고 기존 기획·문안은 보존한다. 외부 ID가 있거나 전송 결과가 불확실한 작업은 이 취소 대상에 넣지 않는다.
3. 일시정지 중 총괄 프로세스가 종료되면 단계가 계속 실행 중으로 표시됐다. 종료한 프로세스가 담당했던 실행을 직접 찾아 확인 필요 상태로 남긴다. 사용자의 paused/stopped 상태나 이후 시작한 다른 실행은 변경하지 않는다. 체크포인트가 저장된 작업과 서버가 관리하는 비동기 영상은 기존 복구 절차를 유지한다.
4. 중지 후 총괄과 도구 하위 프로세스가 계속 살아 있을 수 있었다. 종료 상태를 확인하면 해당 프로세스 그룹을 종료한다. 먼저 종료 신호를 보내고 5초 안에 끝나지 않으면 강제 종료한다. 확인되지 않은 외부 결과는 재생성하지 않고 기록을 보존한다.
5. 중지·일시정지 이후 늦게 도착한 품질 재제작 요청이 저장된 하위 결과를 무효화할 수 있었다. 진행 중인 실행과 단계에만 재제작을 허용한다.
6. 화면에서 다른 변경 요청을 처리하는 동안 제어 버튼 요청이 무시될 수 있었다. 실행 제어를 별도 순서로 처리하고 같은 요청은 중복 접수하지 않는다. 응답을 15초 안에 확인하지 못하면 상태 확인을 안내하며 자동 재전송하지 않는다.

## 동작 기준

- 일시정지는 새 단계·새 영상 제출을 막는다. 이미 진행 중인 단계의 결과는 저장할 수 있고 같은 실행에서 재개한다. 결과를 확인할 수 없는 작업은 재개 전에 확인해야 한다.
- 중지는 해당 실행의 새 제작을 끝낸다. 제출 전 영상은 취소하며 총괄 프로세스도 정리한다. 중지한 실행을 재개하지 않고 새 실행으로 시작한다.
- 이미 외부에 전송 중이거나 전송한 영상의 원격 취소를 보장하지 않는다. 기존 외부 ID로 결과를 조회·다운로드해 보존하며, 중지 후 다음 품질 검수·등록·다음 이야기로 자동 진행하지 않는다.
- 종료 시각이 없어도 제어할 수 있다. 종료 제한이 있는 실행과 없는 실행 모두 같은 중지·일시정지 규칙을 적용한다.

## 검증

- 수정 전 영상 제출 직전 중지·일시정지, 정지 중 작업자 종료, 중지 후 재제작의 4개 회귀 테스트가 실패함을 확인했다. 수정 후 모두 통과했다.
- 전체 Python 테스트 205개, 화면 로직 테스트 8개 통과. 취소 이후 늦은 업로드 오류가 취소 상태를 실패로 덮어쓰지 않는 경우도 포함한다. SQLite 취소 상태 보호 규칙도 검증하여 이미 실행 중인 이전 작업자의 늦은 상태 변경을 차단한다.
- 실제 테스트 하위 프로세스까지 종료되는지, 제출 전 즉시 취소, 전송 완료 후 늦은 결과 보존, 새 실행 보호, 중복 유료 제출 방지를 검증했다.
- 격리 브라우저에서 종료 시각 없이 시작 → 일시정지 → 재개 → 중지 → 새로고침을 확인했다. 실제 AI·유료 생성·SNS 게시는 호출하지 않았다.

## 실제 적용

적용 도중 사용자가 새 영상만 실행 `run-fdb94de359954c75`를 시작했다. 핵심 제어 수정이 로드된 기존 총괄은 유지하고, 작업을 맡고 있지 않은 기본 서버 8765를 갱신했다. 마지막 취소 상태 보호는 공유 SQLite에 적용하여 진행 중인 작업자를 재시작하지 않아도 보호된다. 8765·8767 상태 API 200과 새 실행의 페르소나·설정·running 상태를 확인했다. 자동 제작을 중지·재개하거나 새로 시작하지 않았다. 적용 전 백업은 `.runtime/backups/before-control-review-20260921-193921.sqlite3`다.

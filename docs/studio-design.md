# Boca 스튜디오 대시보드 설계

2026-09-21. 사용자는 자동 생성 예약 화면을 넘어 페르소나 생성부터 콘텐츠 기획·제작·검수·승인까지 일관되게 운영할 대시보드를 요청했다. 기존 단일 장문 화면을 작업별 화면으로 교체한다.

## 정보 구조

| 메뉴 | 사용자가 하려는 일 | 주요 동작 |
|---|---|---|
| 개요 | 오늘 처리할 일 확인 | 현재 페르소나, 검토할 콘텐츠, 최근 기획과 제작 상태, 주요 작업 바로가기 |
| 페르소나 | 일관된 가상 인물 만들기 | 프로필 생성·편집·전환, 성격·말투·생활 배경·외형 기준과 소개글 저장 |
| 콘텐츠 제작 | 어떤 이야기를 만들지 정하고 제작 요청 | 기획안 작성·수정, 형식·GS 계열사 선택, 제작 대기열, 별도 탭에서 연속 자동 생성 제어 |
| 영상 라이브러리 | 만들어진 영상을 다시 보고 진행 중인 제작 확인 | 전체 영상 이력, 재생·다운로드, 제작 상태·실패 사유, 상태 필터·검색, 자동 갱신 |
| 검수·승인 | 이미지와 문안을 보고 게시할 버전 결정 | 상태별 검토, 카드별 보기, 제목·문안·해시태그 수정, 출처 확인, 버전별 승인·반려 |
| 피드 미리보기 | 계정 전체 인상 확인 | 페르소나 프로필, 소개글, 3열 피드, 검토/게시 상태별 확인 |
| GS 소재 | 이야기에서 사용할 사실 정리 | 계열사·브랜드·상품·서비스의 출처와 활용 정보 등록, 유효기간·공개 노출 범위 관리 |
| 활동 기록 | 제작이 어디에서 멈췄는지 확인 | 실제 단계·외부 작업·실패·재시도·제어 이벤트를 검색하고 상세 확인 |
| 설정 | 운영 대상과 연결 상태 관리 | Instagram 대상 계정 정보, 실제 연결 여부, 생성 정책과 로컬 실행 조건 확인 |

자동 생성은 콘텐츠 제작의 한 방식이다. 대시보드 첫 화면과 모든 주요 행동을 일정 예약으로 모으지 않는다. 사용자가 선택한 페르소나와 특정 실행에 저장된 페르소나는 구분하며, 화면 전환이나 페르소나 선택으로 실행 중인 인물을 조용히 교체하지 않는다.

## 시각 방향

- 편집 스튜디오의 작업대처럼 구성한다. 고정 사이드바, 간결한 상단 컨텍스트, 작업에 맞춰 넓이가 달라지는 본문을 사용한다.
- 색상: Canvas #F7F8FA, Paper #FFFFFF, Ink #172033, Muted #697386, Cobalt #4F5CE5, Selected #EEF0FF. 보조 분홍은 작은 프로필 디테일에만 사용한다.
- 한국어를 중심으로 Pretendard Variable을 로컬 제공하고 Apple SD Gothic Neo를 대체 글꼴로 사용한다. 큰 홍보 문구보다 제목·설명·입력값·보조 정보의 구분을 명확히 한다.
- 시각적 특징은 페르소나 프로필과 편집된 피드 미리보기 한 곳에 둔다. 표, 목록, 분할 검토 화면은 정보 밀도와 정렬을 우선한다. 모든 내용을 같은 크기의 카드로 분할하거나 그라데이션을 장식으로 쓰지 않는다.
- 선택한 메뉴, 현재 페르소나, 필터, 저장 전 변경 상태가 항상 구분되어야 한다. 폼의 기본 동작은 저장이며 게시나 외부 연결 성공을 암시하지 않는다.

## 상호작용 원칙

- 새로고침·자동 상태 조회는 작성 중인 입력과 커서를 보존한다.
- 영상 라이브러리(`#videos`)는 3초마다 로컬 저장 상태를 확인하고 진입·창 복귀 시 즉시 확인한다. 상태와 목록은 갱신하되 같은 영상의 플레이어는 유지하여 재생 위치·음량·전체화면을 보존한다. 연결 실패 시 저장된 목록을 유지하고 갱신 실패 상태를 표시한다.
- 영상 이력은 현재 자동 실행과 분리해 유지한다. 등록 전 완료된 자동 영상, 직접 제작 영상, 가져온 콘텐츠의 영상도 조회하며 새 실행이나 문안 수정으로 과거 영상이 사라지지 않는다.
- 메뉴 이동에서 저장하지 않은 변경이 있으면 사용자가 결정할 수 있게 한다. 오류 후에는 입력을 유지한다.
- 빈 화면은 가짜 콘텐츠나 성과 수치를 보여주지 않고, 바로 할 수 있는 다음 행동을 제공한다.
- 계획 초안 생성과 실제 AI 이미지 생성, 내부 프로필 저장과 Instagram 계정 가입·인증을 구분한다.
- 제작 대기열에 넣었다면 그 사실과 실제 시작 조건을 표시한다. 실행 요청을 저장한 것만으로 이미지가 생성 중이라고 표시하지 않는다.
- 승인된 버전 변경은 재승인 대상이다. 사람이 수정한 값은 늦은 AI 응답으로 덮어쓰지 않는다.
- 실행 재시작 복구와 누적 로그는 기존 백엔드 계약을 유지한다. 실물 게시·유료 API 호출은 UI 개편 검증에 포함하지 않는다.
- 작은 화면에서는 사이드바를 축약하고, 목록·편집기·피드가 화면 밖으로 넘치지 않게 재배치한다. 키보드 포커스와 대화상자 닫기 동작을 지원한다.

## 검증

기존 승인·반려·미디어 무결성·게시 중복 방지·연속 생성 복구 테스트를 유지한다. 새 프로필 버전과 콘텐츠 소속, 기획안의 실제 작업자 입력 전달을 별도 검증한다. 브라우저에서는 격리된 DB로 페르소나 생성/수정, 기획 저장/제작 요청, 메뉴·검색·필터, 검토 수정/승인 상태, 소재 저장, 설정 저장을 확인한다. 실제 운영 DB에 검증용 인물·피드·소재를 넣지 않는다.

### 2026-09-21 구현 후 확인

- 스튜디오 관련 단위 테스트 66개 통과. 임시 HTTP 서버에서 페르소나·기획·설정·외형 참조·ZIP·정적 글꼴 API 확인.
- 운영 DB와 분리된 8766 서버에서 프로필 생성·전환, 기획 저장·제작 요청, 수동 실행의 연속 모드 전환·일시정지·재개·중지를 브라우저로 확인.
- 검수 수정 중 새로고침의 입력 보존, 저장 후 v3 승인, 승인 뒤 수정 시 v4 검수 대기 복귀, v3 ZIP 다운로드 확인.
- 워크스페이스 이름·게시 대상 아이디 저장, 계정 미연결 유지, GS 소재 수정·검색 확인.
- 실제 서버에는 테스트 인물·기획·게시물을 추가하지 않았다. 데스크톱 1440px과 모바일 390px에서 8개 화면의 가로 넘침 없음, 로컬 글꼴 정상, 브라우저 오류·경고·CSP 위반 0건을 확인했다.
- 실제 외부 미디어 생성과 Instagram 인증·게시 성공은 이 UI 검증에 포함하지 않는다.

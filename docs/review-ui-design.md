# 종합 콘텐츠 스튜디오 UI 설계

2026-09-21 업데이트. [스튜디오 설계](studio-design.md)의 정보 구조를 기준으로 기존 단일 제작·검토 화면을 작업별 대시보드로 확장한다.

## 목적과 시각 방향

페르소나 설정, 기획, 제작, 검수, 피드 확인을 각각 이해하기 쉬운 화면으로 나눈다. 개요에서는 현재 해야 할 일을 보여주고 자동 생성 제어는 콘텐츠 제작 메뉴의 탭 안에 배치한다.

- 고정 사이드바와 간결한 상단 경로·작업 페르소나 선택기를 사용한다.
- 밝은 회색 배경과 흰 작업 영역, 짙은 글자, 코발트 계열 선택·주요 동작 색을 사용한다. 상태는 색과 텍스트를 함께 표시한다.
- 제목·설명·입력값·보조 정보의 위계를 구분한다. 프로필과 미디어에 시선을 모으고 소재·로그는 정렬된 표와 목록으로 읽게 한다.
- Pretendard 중심의 한국어 글꼴 체계와 시스템 대체 글꼴을 사용한다.
- 인물 참조가 없으면 미등록 상태를 보여준다. 예시 사진이나 임의 성과 숫자를 실제 운영 결과처럼 넣지 않는다.

## 주요 사용 흐름

### 페르소나 생성과 선택

프로필 폼에서 이름, 소개글, 나이·생활 배경, 성격·말투, 취향, 가족, 외형 지침을 정한다. 저장 후 목록에서 작업 대상을 선택한다. 프로필 수정은 새 버전으로 저장하며 현재 실행은 시작 시점의 인물·버전을 유지한다.

프로필 저장, 외형 이미지 생성, Instagram 계정 가입을 각각 다른 행동으로 안내한다. 외형 미생성 상태를 프로필 저장 성공과 혼동하지 않게 한다. 첫 AI 외형 생성과 반복 이미지 일관성은 실제 실행 검증 전이다.

### 기획과 제작 요청

기획 보드에서 제목·의도·형식·계열사를 작성한다. 저장은 초안을 보관하고 제작 요청은 실제 작업자 큐에 전달한다. 제목·의도·형식·페르소나는 단계 작업의 입력으로 유지된다.

수동 기획만 요청하면 해당 큐를 처리한 뒤 멈춘다. 연속 자동 생성은 별도 탭에서 명시적으로 시작한다. 기존 예약이나 일시정지 실행에 연결된 기획은 실제 시작 조건을 확인할 수 있어야 한다. 중복 클릭으로 같은 기획을 여러 번 제작하지 않는다.

### 자동 생성 제어

한국 시간 시작·종료 입력, 현재 실행·단계·작업자 응답, 누적 완성·실패 건수, 시작·일시정지·재개·중지를 제공한다. 총 열 건 제한을 두지 않는다.

순서는 GS 소재 확인 → 일상 기획 → 스토리보드 → 문안 → 미디어 → 품질 검수 → 피드 등록이다. 승인 대기는 다음 제작을 막지 않는다. 요청 저장·시작 예약·작업자 대기·실제 실행·응답 불확실을 구분하고 임의 진행률을 만들지 않는다.

중지나 기한 도달 후 기획안은 실제 상태에 따라 초안 또는 실패 상태로 돌아간다. 실패한 기획은 내용을 확인·수정한 후 새 제작을 요청한다. 외부 작업의 늦은 결과는 기존 순환에 보존하며 새 제작 상태를 덮어쓰지 않는다.

### 검수와 피드 확인

검수 화면은 목록과 편집기를 나란히 두고 미디어·문안·출처를 함께 확인하게 한다. 카드 수는 콘텐츠의 실제 길이를 사용한다. 승인 버튼에 현재 버전을 명시하고 저장 전 수정이 있으면 먼저 저장하도록 한다.

사람이 수정하면 새 버전이 생기고 재승인이 필요하다. AI의 늦은 결과는 별도 제안 건수로 안내한다. 게시 중·게시 완료·게시 결과 확인 필요 상태에서는 문안 변경을 제한한다.

피드 미리보기는 선택한 인물의 내부 프로필과 3열 배치를 보여준다. 생성·검수·승인 상태를 표시하며 실제 Instagram 게시 화면으로 오인하지 않게 한다. 계정 미연결 상태에서도 내부 검수·승인·내려받기는 사용할 수 있다.

## 갱신·편집·접근성

- 서버 상태를 주기적으로 읽되 작성 중인 입력과 커서를 보존한다. 브라우저 타이머는 상태 조회를 담당한다.
- 저장 전 변경이 있는 상태에서 콘텐츠·메뉴를 이동할 때 변경을 버릴지 확인할 수 있게 한다. 저장 오류 뒤에도 입력을 유지한다.
- 서버 연결이 끊기면 마지막 수신 상태임을 알린다. 예약 실행을 미디어 생성 중으로 표현하지 않는다.
- 소재의 확인일·유효기간·노출 범위와 공개 문안을 구분한다. GS SHOP 판매처 비노출 원칙과 내부 출처 보존을 함께 유지한다.
- Instagram 계정명 저장 화면에 인증 미완료를 명시한다. 저장 성공 메시지가 연결·가입·게시 성공을 암시하지 않게 한다.
- 키보드 포커스, 본문 바로가기, 대화상자 이름과 닫기 동작을 제공한다. 상태는 색에만 의존하지 않는다.
- 좁은 화면에서는 사이드바를 메뉴로 축약하고 목록·편집기·폼을 세로로 재배치한다. 표는 필요한 영역에서 스크롤하며 본문 전체가 가로로 밀리지 않게 한다.

## 현재 구현 경계와 검증

여러 페르소나 생성·조회·버전 수정·선택, 실제 제작 입력에 연결되는 기획안, 연속 실행 제어, 버전별 검수·승인, 선택한 인물의 피드, 소재·로그·설정 화면이 구현되어 있다. 페르소나·기획안 삭제, 카드별 재생성 화면, 버전 비교 화면, 실제 Instagram OAuth·프로필 변경·SNS 게시는 후속 기능이다.

서버는 임시 SQLite와 검증용 파일로 66개 테스트를 통과했다. 페르소나 전환·버전·외형 참조, 기획의 실제 제작 입력과 중단 후 재제작, 사람 수정·승인 보존을 확인했다. 실제 AI 외형 생성·야간 무인 생성·Instagram 게시 성공 검증과는 구분한다.

화면 검증은 격리된 DB로 메뉴 이동, 프로필·기획·소재·설정 저장, 제작 요청, 검수 수정·승인, 모바일 배치와 입력 보호를 확인한다. 검증용 프로필·피드·소재를 실제 운영 데이터에 넣지 않는다.

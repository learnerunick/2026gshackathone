# 대시보드 기능 검토 — 페르소나 콘텐츠 스튜디오

2026-09-21 업데이트. 실제 화면과 저장·실행 동작을 기준으로 작성한다. 시각 방향은 [스튜디오 설계](studio-design.md), 세부 계약은 [로컬 API](local-api.md)를 따른다.

## 제품 정의

Boca는 가상 인물의 프로필을 만들고, 그 인물의 일상 이야기를 기획·제작·검수하는 콘텐츠 스튜디오다. 페르소나 생성부터 피드 전체 인상 확인까지 하나의 작업 공간에서 이어진다. 자동 생성은 ‘콘텐츠 제작’ 안에서 선택하는 제작 방식이다.

여러 페르소나를 저장하고 작업 대상을 전환할 수 있다. 현재 Instagram 대상 계정 설정은 작업 공간 공통이며, 실제 OAuth와 게시 연결은 아직 완료되지 않았다. 내부 프로필을 저장해도 Instagram 계정이 개설되거나 실제 프로필 사진·소개글이 변경되지 않는다.

## 확정된 콘텐츠 방향

- 공감, 일상 공유, 취향 발견을 중심으로 한 실사형 가상 인물의 일상 로그다.
- 첫 페르소나는 한국인 30대 후반 워킹맘이다. 여의도에서 일하고 목동에 거주하며 집 가꾸기를 좋아한다. 계획적이고 실용적인 성격과 간결한 말투를 사용한다. 엄마와 닮은 다섯 살 외동딸은 가끔 등장한다.
- 이야기를 먼저 정하고 GS리테일(편의점,수퍼)·GSSHOP·GS건설·GS칼텍스·파르나스 호텔의 자료 중 어울리는 소재를 연결한다. 출처는 내부에 보존하며 GS SHOP 판매처명·로고는 공개 콘텐츠에 넣지 않는다.
- 가상 인물 표시를 유지한다. 실제 구매·사용 경험이나 차량·주택 소유를 임의로 주장하지 않는다.
- 카드 수는 이야기마다 달라진다. 약 다섯 장과 시연용 열 건은 참고치이며 고정 장수나 총 생성 상한이 아니다.
- 이미지와 선택 영상은 연결된 도구가 지원하는 범위에서 제작한다. 추가 유료 AI API 결제를 전제로 하지 않는다.
- 사람이 특정 콘텐츠 버전을 승인한 뒤에만 게시 대상으로 삼는다. AI 품질 검수는 사람의 승인을 대신하지 않는다.

## 두 가지 제작 방식

### 기획안 제작

1. 작업 페르소나를 선택한다.
2. 기획 제목과 전달할 장면, 형식, 연결할 계열사를 저장한다.
3. 제작 요청으로 기획안을 대기열에 넣는다.
4. 작업자는 실제 기획의 제목·의도·형식·페르소나를 입력으로 받아 제작한다.
5. 완성본을 검수 대기로 등록한다. 수동 기획만 처리하는 실행은 대기열이 비면 종료한다.

동일 기획의 중복 요청은 실행·순환을 중복 생성하지 않는다. 기존 동일 페르소나의 실행이 있으면 그 실행에 연결하며 예약 시각이나 일시정지 상태를 임의로 바꾸지 않는다. 현재는 동시에 하나의 제작 실행을 운영한다. 다른 페르소나나 새 프로필 버전으로 실행하려면 기존 실행을 먼저 정리한다.

### 콘텐츠 자동 생성

‘콘텐츠 제작 → 콘텐츠 자동 생성’에서 시작·종료 시각과 현재 상태를 확인하고 시작·일시정지·재개·중지한다. 실행 중에는 다음 흐름을 반복한다.

```text
GS 소재 확인 → 일상 기획 → 스토리보드 → 문안·해시태그
→ 미디어 제작 → 품질 검수 → 피드 등록·검수 대기 → 다음 이야기
```

- 열 건을 넘겨도 종료 시각이나 중지 조건 전까지 다음 이야기를 만든다.
- 승인 대기는 다음 콘텐츠의 제작을 막지 않는다.
- 수동 기획 실행에서 자동 생성을 명시적으로 시작하면 연속 모드로 전환한다.
- 단계 결과, 외부 작업 ID, 시도 횟수, 체크포인트를 저장한다. 응답을 잃은 작업을 확인 없이 재호출하지 않는다.
- 중지·기한 종료 후 시작 전 기획안은 초안으로 돌아간다. 중간에 멈춘 기획안은 결과를 보존하고 수정 후 새 제작을 요청할 수 있다. 진행 중 외부 작업의 늦은 결과는 원래 순환에 남긴다.
- 재시도·대기 한도는 총 생성 상한과 별개다. 실패 사유와 중단 조건은 활동 로그에서 확인한다.

## 페르소나·버전·외형 일관성

선택한 작업 페르소나와 실행에 저장된 페르소나 스냅샷을 구분한다. 다른 인물을 선택하거나 프로필을 수정해도 진행 중인 실행의 인물·버전은 바뀌지 않는다. 기존 콘텐츠는 원래 페르소나 버전으로 계속 검수할 수 있다. AI 결과가 콘텐츠를 다른 페르소나에게 옮기거나 실행 버전을 섞을 수 없다.

엄마·딸의 기준 이미지는 페르소나 버전별로 별도 보관한다. 최초 등록 결과를 변경 불가능한 파일로 복사하고 해시를 기록한다. 같은 이미지 재등록은 중복 처리하며 같은 버전의 외형 바꿔치기는 거부한다. 최초 기준 이미지는 해당 버전의 실행에도 반영하지만 저장된 프로필 원문과 초기 config를 덮어쓰지 않는다. 새 외형은 새 페르소나 버전에서 관리한다.

프로필 생성·버전 관리·기준 이미지 보관 경로는 구현되어 있다. 실제 AI가 엄마와 딸의 외형을 처음 만들고 여러 피드에서 일관되게 재사용하는 전 과정은 첫 실제 실행에서 확인해야 한다.

## 검수와 게시의 경계

콘텐츠는 생성 즉시 검수 대기로 들어간다. 사람이 수정하면 새 버전이 부여되고 승인은 그 버전과 미디어 해시에 연결된다. 늦은 AI 결과는 사람 수정본·승인본을 덮어쓰지 않고 별도 제안으로 보관한다.

게시 기록·단일 게시 소유권·중복 방지 동작과 실제 Instagram 연결은 구분한다. 실제 계정 인증, 게시 도구, 게시 가능한 미디어 경로를 확인하기 전에는 게시 완료로 표시하지 않는다. 게시 성공은 실제 게시물 URL 등 확인 가능한 결과로 기록한다.

## 저장 구조와 확인 범위

- 페르소나·리비전·버전별 외형 참조·현재 선택을 SQLite에 보관한다.
- 기획안은 페르소나에 연결되고 제작 요청 후 실행·순환·완성 콘텐츠 ID로 이어진다.
- 실행은 페르소나·설정 스냅샷을 소유한다. 순환은 단계 작업·결과·소유권·외부 작업 ID를 보관한다.
- 콘텐츠 리비전은 미디어·문안·소재 출처와 연결되고, 승인·게시 기록은 특정 리비전을 참조한다.
- Instagram 대상은 작업 공간 공통이다. 페르소나별 실제 계정 인증 관계는 후속 연결 과제다.

임시 SQLite와 검증용 미디어를 사용한 66개 테스트가 통과했다. 페르소나·기획안·중단 복구·외형 참조·버전 승인·중복 게시 방지의 서버 동작을 확인한 결과이며 무인 AI 생성 품질이나 실제 SNS 게시 성공을 뜻하지 않는다.

# 자동 제작 개수 옵션 및 전체 로직 점검

검증일: 2026-09-21. 실제 생성·게시를 호출하지 않는 격리 DB, 합성 미디어, 공급자 대역과 브라우저로 검증했다.

## 추가한 동작

- 콘텐츠 제작 → AI 자동 제작 → 콘텐츠 개수에서 ‘제한 없이’ 또는 ‘개수 지정’을 선택한다. 지정 범위는 1~1,000건이다.
- 시작 요청의 `stop_after_posts`는 null 또는 정수이며 실행 설정에 고정된다. 현재 실행의 설정은 중지 후 새 실행에서 바꾼다.
- 해당 실행에서 피드 등록을 끝낸 콘텐츠만 한 건씩 센다. 카드 장수, 영상 파일 수, 실패, 재시도, 기존 콘텐츠, 사람의 승인 횟수와는 관계없다.
- 목표 도달 시 마지막 등록과 같은 트랜잭션에서 완료 처리한다. 목표 또는 종료 시각 중 먼저 도달한 조건에서 멈춘다. 중복 요청·재시작·재개로 새 순환을 추가하지 않는다.
- 대시보드에 완료/목표 진행률과 종료 사유를 표시한다. 로그에도 목표·완료 수와 `run.completed`를 기록한다. 기본값은 기존과 같이 제한 없음이다.

## 검증 근거

- `python3 -m unittest discover -s tests -v`: **167개 통과**. 로그: `.runtime/quantity-full-tests-final.log`.
- 새 개수·재작업·전문가 무효화 테스트 10개, 영상 회귀 테스트 5개, 검수/API 회귀 테스트 3개를 포함한다.
- 기본 소재 조사 및 7개 전문가 계약을 모두 켠 실행에서 목표 1건 종료를 통합 검증했다. 이는 실제 웹·모델 응답 대신 명시적인 대역 결과를 사용한 계약 테스트다.
- JavaScript 문법 검사: app.js, production-guides.js, video.js 통과.
- 격리 대시보드 `8784`에서 폼 → API → DB → 자동 화면 갱신을 확인했다. 합성 등록 2건 후 completed, count=2, cycle=2. 운영 DB에 테스트 데이터를 넣지 않았다.

## 실제 운영에서 남은 검증 범위

서버 단독으로 AI를 실행하는 구조가 아니며 Codex heartbeat·실제 서브에이전트·외부 생성 도구가 필요하다. 이번 검사는 유료 이미지·영상 API나 실제 Instagram 전송을 실행하지 않았다. 실제 Instagram 인증·게시 커넥터는 아직 연결되지 않았으므로 승인 결과는 게시 대기로 보관된다. 실제 콘텐츠 품질·여러 피드의 얼굴 일관성·밤사이 전체 실행 시간은 실제 생성 운영에서 별도 확인해야 한다.

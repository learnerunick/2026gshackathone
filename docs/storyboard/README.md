## 조사 범위와 한계

Instagram의 네 프로필 첫 화면과 게시물 링크 목록을 확인하고, 계정마다 3개씩 총 12개 게시물 원문을 열었다. 선택 기준은 프로필에서 접근 가능한 최근 게시물과 대표 고정 게시물, 일상·상품 연결·정보 제공 방식의 차이다. 무작위 표본이나 계정 전체 분석이 아니다.

브라우저에서 본문·실제 이미지·재생 중 서로 다른 시점의 화면을 확인했다. 영상은 표본 프레임 관찰이며 전편의 연속 시청, 전체 컷 수 측정, 음성 청취·전사는 수행하지 않았다. 오디오명은 Instagram 표기만 확인했다. 실제 영상 자산 내보내기가 실패해 원본 MP4와 타인의 이미지·음원을 저장소에 보관하지 않는다. 공개 댓글의 개인 정보와 원문도 자료에 옮기지 않는다.

게시일은 게시물 페이지의 time 요소를 우선해 한국 날짜로 기록했다. 프로필 썸네일의 자동 설명 날짜와 다른 경우가 있어 썸네일 날짜를 대신 쓰지 않았다. 제품명·가격·할인·효능은 창작자의 게시 내용이며 GS 상품 사실 자료로 검증하거나 등록하지 않았다. 조회·좋아요 수로 성공 원인, 시청 유지율, 구매 효과를 추정하지 않았다.

| 표본에서 관찰한 장치 | 우리 콘텐츠에 적용할 제안 | 그대로 가져오지 않을 것 |
|---|---|---|
| sinji_in: 생활 조건을 제목으로 제시하고 상황 진행을 보여줌 | 시작에 작은 궁금증, 시간·행동의 진전 | 실제 부부 이력, 예산·구매담, 고유 문구 |
| kiims_haus: 공간 전후 비교와 구체적인 스타일링 정보, 개인 일상 병행 | 결과 차이를 눈으로 보여주고 일상의 사연을 붙임 | 타인의 집·반려동물 사연·상업 프로젝트 |
| ssbangunni: 선명한 선택 의견, 인물 반응, 비교 화면 | TJ 캐릭터의 선택 기준 하나와 시각적 근거 | 품절 예언, 실사용 후기, 댓글 자동 DM 유도 |
| y_j__habibi: 짧은 몸짓·스타일 변화, 생활 공간의 상품, 디테일 화면 | 얼굴·행동·디테일의 거리 변화와 간결한 문안 | 실제 얼굴·체형·목소리·화장, 같은 포즈 연쇄 |

위 적용안은 표본에서 착안한 편집 판단이다. 각 계정이 늘 같은 방식으로 제작한다는 뜻이 아니다.

## 직전 영상의 설계 진단

대상: `run-fdb94de359954c75-c0001:storyboard`, 제목 `내일 챙길 건, 하나만`, 연결 영상 `video-c55d74162d634537bf8efeb16740994d`.

저장된 스토리보드와 video_prompt에서 확인한 사실:

- 20초 전체가 한 고정 미디엄 숏이며 컷·줌·카메라 이동을 금지했다.
- 0–4초 망설임, 4–14초 손수건을 접어 가방에 넣기, 14–20초 안도하는 표정이다.
- 내레이션·대사·생성 자막도 제외했다. 작성 당시 계약이며 현재의 보이스·자막 정책과는 다르다.

편집 판단: 손수건을 넣는 단일 행동의 전후 차이가 작고, 관객에게 먼저 제시한 질문이나 비교 기준이 약하다. 인물 오류를 줄이는 제약이 화면의 새로운 정보까지 없앤 것으로 보인다. 이는 **저장된 설계에 대한 진단**이며 이 문서에서 완성 MP4를 연속 시청했다고 주장하지 않는다. 수정 방향은 컷 수 자체를 늘리는 것보다, 관객이 알아볼 선택·발견·결과를 먼저 만드는 것이다.

## 실제 연결과 적용 시점

`config/specialists.json`의 스토리보드 역할에 제작 지침 본문·경로·SHA-256을 `playbook`으로 함께 저장한다. 신규 run은 기존 `_freeze_specialists`를 통해 이 본문까지 동결하고, 해당 단계의 `job.input_json.specialist.playbook`으로 전달한다. 경로를 적어두기만 하는 연결이 아니다. 기획·문안·비주얼·검수 역할에도 각자의 인계 기준을 추가한다.

현재 run, 기존 스토리보드, 사람 수정본·승인, 페르소나 버전은 소급 변경하지 않는다. 기존 실행의 재개는 기존 동결 지침을 사용하며, 새 역할 묶음은 **새로 시작하는 실행**에 적용된다. 이 작업은 생성 실행·재시도·비용 증액·SNS 게시를 시작하지 않는다.

대시보드의 `영상 MD`는 낮은 관여도의 분위기 자료다. 이번 제작 지침은 역할의 작업 기준으로 연결하고, 계정별 분석을 영상 MD 목록에 대량 등록하지 않는다. 기존 분위기 MD를 합쳐 최대 1~2개 요소만 선택적으로 사용하는 정책은 유지한다.

검증: 전문 역할 관련 기존 테스트 11개 통과. 격리 저장소에서 역할 묶음 v4로 새 run을 만들고 이후 설정 파일을 바꿔도, 스토리보드 단계에 원래의 MD 본문·해시가 그대로 전달되는 것을 확인했다. 예시 대사는 현재 자막 길이·속도·시간 제약을 통과한다. 실제 미디어 생성이나 SNS 게시를 테스트하지 않았으므로 새 영상의 재미·연출 정확도는 아직 미검증이다.

## 자료를 계속 쌓는 방법

새 조사에는 `research/YYYY-MM-DD/계정.md`를 추가한다. 게시물 URL·게시일·확인일·형식·실제로 본 범위·관찰·적용 제안·미검증 항목을 남긴다. 정정은 이유를 붙이고, 기존 관찰을 나중의 인상으로 조용히 바꾸지 않는다. 제작 기준을 바꿀 때는 `director-playbook-v2.md`처럼 새 버전을 만들고 역할 묶음의 버전과 스냅샷도 함께 갱신한다.

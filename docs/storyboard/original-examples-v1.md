# 독창적 연출 연습안 v1

2026-09-21. 참고 게시물의 대본을 옮기지 않고 boca 페르소나를 위해 새로 쓴 **미제작 예시**다. 실제 GS 상품 연결·소재 유효성 검증·생성 모델 실행은 아직 하지 않았다. 최근 피드와 겹치면 사용하지 않는다. 매 회차 이 구조를 반복하지 않는다.

## 연습 1: 정돈의 기준을 바꾸는 엄마

일상: 정돈된 테이블을 만들려다 딸이 남긴 작은 종이 그림을 본다. 궁금증: 깔끔함과 애정 사이에서 무엇을 남길까. 캐릭터: 기준을 정하는 TJ 성격이지만 기준을 스스로 바꿀 수 있다. 딸의 얼굴·목소리는 등장하지 않는다. 그림은 읽을 글자·상품·실제 아동 자료 없이 새로 만든 단순한 가상 소품이다.

| 시간 | 화면과 행동 | 새 정보 / 대사 제안 |
|---|---|---|
| 0–3초 | 테이블 끝에 비뚤게 놓인 작은 종이와 가지런한 나머지 물건. 손이 종이에 다가간다. | 곧 치울 것 같은 기대. 0.3–2.8초: `이것만 치우면 끝인데.` |
| 3–7초 | 가까운 화면. 글자 없는 서툰 해·집 그림을 보고 손이 멈춘다. | 어수선한 종이가 딸의 그림이라는 의미. 3.5–6.5초: `다섯 살 취향은 못 치우지.` |
| 7–12초 | 같은 엄마가 종이를 버리는 대신 테이블 위 작은 받침에 세운다. 복잡한 접기·클립 조작은 없다. | 기준을 바꾼 선택. 8–11초: `정리 기준, 하나 수정.` |
| 12–17초 | 첫 장면과 대응하는 넓은 구도. 종이는 남았지만 놓는 방식이 바뀌었다. | 결과를 같은 화면으로 비교. 13–16초: `좋아하는 건 잘 보이게.` |
| 17–20초 | 엄마가 그림을 한 번 보고 의자를 당겨 앉는다. | 감정과 생활이 이어지는 마무리. 새 설명 없이 짧은 쉼. |

이는 5개 의미 구간의 예시이며 반드시 5개의 컷을 생성하라는 뜻은 아니다. 한 번의 생성에서 전환이 불안정하다면 동일 공간의 단일 숏에서 손의 멈춤·그림의 이동·완성 공간이 분명히 보이도록 재구성한다. 이번 run의 입력 길이가 20초가 아니면 시간표를 새로 설계한다.

제품 연결 후보는 그림을 두는 작은 소품 정도다. 실제 GS 판매 자료가 없으면 무표식 가상 소품으로 두며 상품명을 지어내지 않는다. 가상 일상 고지는 게시 문안에 포함한다.

## 연습 2: 같은 자리의 두 분위기

일상: 퇴근 뒤 집에서 업무를 마무리하다 같은 자리를 쉬는 자리로 바꾸고 싶어진다. 궁금증: 큰 가구 이동 없이 무엇을 바꾸면 달라질까. 계정의 공간 전후 비교에서 일반 원리만 참고한 새 기획이다.

도입 후보는 완성 공간의 일부, 화면 안에 남은 업무 흔적, 두 배치의 비교 중 이야기와 최근 피드에 맞는 하나를 고른다. 멀리서 책상 상태를 보여준 다음 손이 작은 물건의 위치를 바꾸는 가까운 화면, 조명과 여백이 달라진 같은 구도, 그 자리에 앉는 인물로 연결할 수 있다. 소품 나열이나 방 전체를 천천히 훑는 화면만 이어 붙이지 않는다.

한국어 대사 후보: `책상은 그대로인데.` → `오늘 일은 여기까지.` → `이제 내 시간으로.` 실제 상품 효능·눈 피로 개선·실제 사용 만족을 말하지 않는다. 정확한 시간표와 대사는 현재 길이·참조·상품 출처를 확보한 뒤 정한다.

## 약한 설계를 바꾸는 기준

`예쁜 사람이 천천히 물건을 정리하고 미소 짓는다`만으로 끝나면 무엇을 남기거나 바꾸었는지 관객이 알기 어렵다. 물건을 더 추가하거나 카메라만 흔드는 대신, 시작의 기대와 인물이 한 선택, 마지막에 보이는 차이를 먼저 쓴다. 새 영상의 실제 재미는 생성 후 사람이 검토해야 한다.

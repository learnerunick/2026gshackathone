# Boca

가상 인플루언서의 페르소나, 일상 콘텐츠, 검수와 승인을 관리하는 로컬 콘텐츠 스튜디오입니다. GS 계열사의 공개 소재를 이야기와 연결하고, 사람이 승인한 버전만 게시 대상으로 다룹니다.

소재 수집 대상은 **GS리테일(편의점,수퍼) / GSSHOP / GS건설 / GS칼텍스 / 파르나스 호텔**입니다. GS리테일은 GS25·GS THE FRESH 범위로 수집하며, [공식 출처·수집 정책](docs/source-research.md)을 따릅니다.

## 실행

Python 3.9 이상으로 실행합니다. 백엔드는 표준 라이브러리와 SQLite를 사용합니다.

```sh
python3 apps/backend/server.py serve
```

브라우저에서 http://127.0.0.1:8765 를 엽니다. 다른 포트는 `serve --port 8766`으로 지정합니다.

## 작업 흐름

1. **페르소나**에서 인물의 프로필·생활 배경·성격·말투를 만들고 저장합니다.
2. **콘텐츠 제작**에서 직접 기획안을 요청하거나 AI 자동 제작 탭을 사용합니다. 자동 제작은 GS 공식 소재 웹 탐색·자동 등록 → 일상 기획 → 스토리보드 → 문안 → 이미지·영상 → 품질 검수 → 피드 등록 → 다음 이야기까지 반복합니다. ‘제한 없이’ 또는 ‘개수 지정(1~1,000건)’을 선택합니다. 지정한 개수의 콘텐츠가 피드로 등록되거나 종료 시각에 도달하면 멈춥니다.
3. **GS 소재**에서 자동 수집 결과·검색어·본문 근거와 출처·유효기간·노출 범위를 확인합니다. 필요한 자료를 수동으로 추가할 수도 있습니다. [자동 탐색 방식](docs/source-research.md)을 참고하세요.
4. **검수·승인**에서 이미지·문안·출처를 확인하고 특정 버전을 승인하거나 반려합니다. 문안을 바꾸면 다시 승인해야 합니다.
5. **피드 미리보기**에서 페르소나별 3열 피드의 전체 분위기를 확인합니다.
6. **활동 기록**에서 실제 제작 단계, 입력·중간 결과·실패·복구 내역을 확인하고 로그 파일을 다운로드합니다.

**콘텐츠 제작 → 제작 결과**에서 저장된 콘텐츠의 이미지·영상·게시 문안을 확인합니다. 영상은 화면에서 재생할 수 있습니다. **AI 자동 제작 → 단계별 결과**에서는 기획, 장면별 스토리보드, 문안·해시태그, 생성 미디어와 검수 결과를 순서대로 읽고 원본 JSON도 내려받을 수 있습니다. 제작 중 체크포인트에 저장된 미디어는 피드 등록 전에도 확인할 수 있습니다.

**제작 현황**(`/#production`)은 자동 제작의 별도 상세 화면입니다. 실행 중에는 모든 화면 상단에 현재 상태·단계·완료/목표 수 버튼이 표시되며 클릭하면 이동합니다. 작업자 연결 대기·예약·실제 제작·일시정지·확인 필요를 구분하고 5초마다 갱신합니다. 미저장 문안과 영상 재생은 상태 갱신 중에도 유지합니다. 상세 화면에서 고정된 페르소나, 현재 콘텐츠의 7단계 흐름, 담당 전문가, 완료 수, 일정, 실패 사유, 단계별 결과와 LOG/JSONL을 확인하고 일시정지·재개·중지할 수 있습니다. 실행이 끝나면 상단 버튼은 숨겨지며 사이드바의 ‘제작 현황’에서 마지막 기록을 볼 수 있습니다. 연결 실패 시 마지막 확인 상태임을 알립니다.

**AI 자동 제작의 전문가 팀**은 소재 리서처·일상 기획자·스토리보드 디렉터·카피라이터·비주얼 프로듀서·독립 품질 검수자·피드 패키징 에디터로 나뉩니다. Codex 제작 총괄이 실제 서브에이전트에게 단계별로 위임하고, 대시보드와 로그에 담당자·결과 인계를 저장합니다. 설정된 역할과 실제 배정 상태를 구분하며 사람의 최종 승인은 유지합니다. [전문가 구성과 운영 방식](docs/specialist-agents.md)을 참고하세요.

**영상 라이브러리**(`/#videos`)는 제작된 영상을 계속 보관해 다시 볼 수 있는 별도 화면입니다. 완료 영상과 진행 중인 작업을 함께 보여주며 3초마다 상태를 확인해 바뀐 내용을 반영합니다. 재생 중인 영상은 상태 갱신 때문에 처음으로 돌아가지 않습니다. 로컬 DB와 미디어 파일을 유지하면 서버를 재시작하거나 새 제작을 시작해도 이전 영상 이력을 볼 수 있습니다.

대시보드에서 페르소나를 저장하는 일과 실제 Instagram 계정을 가입·인증하는 일은 별개입니다. 내부 프로필은 실제 SNS 계정에 자동 반영되지 않습니다. SNS 대상 계정을 저장해도 연결 완료로 처리하지 않습니다.

## 생성 및 실행 환경

현재 AI 작업자는 Mac 서버의 `LocalProductionWorker`입니다. 버튼은 서버에 실제 작업 요청을 저장하고, 작업자가 기존 Codex CLI 로그인과 도구를 사용해 기획·제작·검수·등록합니다. Mac과 백엔드 서버가 실행 중이고 기존 Codex 인증·도구를 사용할 수 있어야 하며 실제 계정의 사용 한도 안에서 동작합니다. [로컬 작업자의 실행·복구 방식](docs/local-production-worker.md)을 참고하세요.

자동 생성의 형식은 이미지(`images`), 이야기별 이미지·영상(`mixed`), 영상만(`video_only`)으로 선택합니다. 영상만 모드는 제작 조건이 맞지 않으면 이미지로 전환하지 않고 확인 대기합니다. 기존 API의 영상 우선(`video`)도 호환용으로 지원합니다. 현재 UI 기본값은 사용자가 승인한 `mixed`이며, 시작한 실행의 형식과 페르소나 버전은 고정됩니다. 기존 실행은 사용자가 중지한 상태로 인계되었으므로 다시 진행하려면 대시보드에서 시작 버튼을 눌러야 합니다. 서버 재시작이나 문서 변경이 중지한 실행을 재개하지 않습니다.

AI 품질 검수는 사람의 게시 승인과 다릅니다. Segmind 자동 영상은 이미 승인한 한도 안에서 사용하고 크레딧을 추가 구매하지 않습니다. 외부 작업 결과가 불명확하면 중복 생성·게시를 막고 확인 대기로 보존합니다.

## Segmind 영상 제작

스튜디오 상단 **영상 제작** 또는 http://127.0.0.1:8765/video 에서 API 키를 연결하고 약 30초 영상을 직접 요청할 수 있습니다. 자동 생성에서도 AI가 작성한 기획·스토리보드·문안을 Segmind 작업자에 전달하므로 영상 폼을 매번 작성할 필요가 없습니다. API 키 인증은 생성 요청이 아니며 실제 영상 제출 시 구독 크레딧을 사용합니다.

자동·수동 영상은 한 편 예상 $8·UTC 하루 예상 $15·대기/진행/확인 필요 2건의 기존 제한을 공유합니다. 자동 영상의 API 키·기준 이미지·한도 조건이 맞지 않으면 사유를 기록하고 이미지 피드로 계속합니다. 완료 영상은 AI 품질 검수 뒤 콘텐츠로 등록하고, 사람의 정확한 버전 승인을 기다립니다. 실제 Instagram 연결과 전송은 별도입니다.

기본값은 Seedance 2.5 · 30초 · 세로 9:16 · 720p입니다. [연결 방법·비용 한도·복구 안내](docs/segmind-video.md)를 참고하세요. 실제 API 키를 입력하기 전에는 계정 연결 완료로 표시하지 않습니다.

## 상세 제작 로그

실행마다 `.runtime/production/<run_id>/events.log`, `events.jsonl`과 `cycles/<cycle_id>/<stage>.json`을 저장합니다. 단계별 입력·출력·체크포인트·시도·외부 ID·공개 선택 근거 요약을 확인할 수 있습니다. 파일은 커밋된 DB에서 원자적으로 교체하며 재시작 시 복구합니다.

```sh
tail -F .runtime/production/RUN_ID/events.log
```

활동 로그의 다운로드 버튼이나 `GET /api/runs/RUN_ID/artifacts`에서 실제 파일 목록을 확인합니다. API 키·소유권 토큰·내부 사고 과정은 내보내지 않습니다.

## 데이터와 협업

- `apps/backend/`: 검토·제작·스튜디오 API.
- `apps/dashboard/`: 대시보드 화면과 정적 자산.
- `config/`: 초기 페르소나, 실행 정책과 일정.
- `.runtime/`: 로컬 SQLite DB, 변경 요청용 인증정보, 원본과 분리된 미디어. Git 제외.
- `output/`: 생성 결과·프롬프트·검증 산출물. Git 제외.
- `tests/`: 콘텐츠 버전, 승인, 연속 제작, 페르소나와 기획안의 독립 테스트.

서버는 기본적으로 이 Mac의 loopback 주소에서만 동작합니다. DB·인증정보를 Git에 올리지 않습니다. Vercel 원격 접속은 아래 안내의 별도 인증 브리지를 사용합니다.

## 검증과 운영 지침

### Vercel에서 현재 AI 제작 방식 사용

Vercel에는 대시보드와 인증 중계 API를 배포하고, AI 제작·SQLite·미디어는 현재 Mac에서 계속 실행하는 구성을 제공한다. 로그인 없는 해커톤 MVP 접근, API 요청 서명, 영상·ZIP 스트리밍, 이미지 분할 업로드를 포함한다. Mac 서버와 HTTPS 터널이 실행 중이어야 한다. [환경변수·실행·Git/Vercel 배포 안내](docs/vercel-local-worker.md)를 따른다.

```sh
npm run build
npm run test:remote
```

기존 로컬 기능도 다음 명령으로 검증할 수 있습니다.

```sh
python3 -m unittest discover -s tests -v
node --check apps/dashboard/app.js
```
